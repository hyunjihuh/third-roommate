# C1 자유 조건 실제 모델 시험, 2026.10.12 04시

배포된 서버 함수(gpt-4.1)에 앱이 보내는 C1 프롬프트를 그대로 넣고 돌렸다. 데모 방(요청자 하늘, 바다 자는 중).
카드 답은 두 가지(먼저 물어봐줘 / 그냥 해도 돼), 조건은 바다가 직접 적은 한 줄.

| 조건 | 문장 | 결과 |
|---|---|---|
| 15분 안으로만 | 내일 저녁 8시에 방에서 10분만 통화해도 돼? | 바로 답 (met) |
| 15분 안으로만 | 지금 방에서 통화 좀 할게 | 되묻기 "통화는 몇 분쯤 할 거예요?" |
| 15분 안으로만 | 오늘 밤 12시에 방에서 30분 통화해도 돼? | 묻기 (not_met) |
| 15분 안으로만 | 오늘 밤 11시에 방에서 40분 통화할게 | 묻기 (not_met) |
| 쓰고 제자리에 둬줘 | 네 드라이기 좀 빌려 써도 돼? | 바로 답 + "쓰고 제자리에 둬주세요." |
| 없음 | 방에서 떡볶이 먹어도 돼? | 바로 답 |
| 먹고 나서 환기랑 정리만 해줘 | 방에서 떡볶이 먹어도 돼? | 바로 답 + "다 먹고 나서 환기랑 정리만 해주세요." |
| 먹고 나서 환기랑 정리만 해줘 | 방에서 치킨 먹고 내일 아침에 치울게 | 묻기 (not_met) |
| 자기 전에는 치워줘 | 방에서 치킨 먹어도 돼? | 바로 답 + "자기 전에는 치워만 주세요." |
| 냄새 심한 건 빼고 | 방에서 마라탕 먹어도 돼? | 묻기 (not_met) |
| 밤 10시 전에만 | 밤 11시에 방에서 라면 먹어도 돼? | 묻기 (not_met) |
| 먼저 물어봐줘 | 네 침대에 잠깐 앉아도 돼? | 묻기 |
| 아직 안 정함 | 주말에 친구 데려와도 돼? | 묻기 |
| 기숙사 규칙 | 친구 자고 가도 돼? | 규칙 |
| - | 아침 드라이기 소리 때문에 자꾸 깨 | 바라는 일 |
| 카드 없음 | 에어컨 22도로 틀어도 돼? | 묻기 |

- 16/16 기대대로, 잘못 허락 0.
- 고치기 전 프롬프트에서 본 문제 두 개를 고쳤다: (1) 조건 없는 카드에 예시 문장을 그대로 옮겨 "지킬 것"을 지어냄(코드가 조건 없는 카드면 안 보여주게 막고 있었음), (2) 30분이라고 말했는데 "몇 분"을 다시 물음. 예시를 가짜 카드(x1)로 바꾸고 not_met 예시와 "이미 있는 정보는 다시 묻지 않는다"를 넣었다.
- 한 번씩만 돌렸다. 자유 조건은 코드가 직접 확인할 수 없어서 모델의 cond_check가 met / keep일 때만 바로 답하고, 나머지는 전부 룸메에게 묻는다.
