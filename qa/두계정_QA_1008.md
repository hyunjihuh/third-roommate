### B1. 기숙사 규칙에 걸리면 화면에 답이 안 나옴 [높음]
- 재현: A 홈에서 "이번 주말에 친구 방에서 자고 가도 돼?" 말하기
- 기대: 기숙사 규칙이라 둘이 정할 수 없다는 멈춤 안내
- 실제: 2초 뒤 대화창이 "무슨 일이에요?"로 돌아감. 편지함에만 "기숙사 규칙"으로 남음

### B2. 같이 맞춰보기에서 B(거절한 쪽) 질문이 A(요청한 쪽) 질문과 같음 [높음]

- 실제: "A 장소를 방에서 휴게실로 바꿈 / B 방이 아닌 다른 장소 사용을 부탁함". 대안 목록에선 "하늘: ... · 바다: ..."로 잘 나옴
- 같은 종류:
  - 설정 "듣는 말투" 예시 문장이 "B가 아침 7시 반쯤..." / "B 부탁: 평일 7:30..."로 고정. B 본인 화면에서도 "B가"로 나옴
  - 첫 화면 "내가 만든 방이야 (A로 들어가기)"
  - 룸메가 이름을 넣기 전 카드 정하기 화면 "B가 이걸 하고 싶을 때", 카드 탭 "B 기다리는 중" (이름이 없을 때라 어쩔 수 없긴 한데 "룸메"가 더 자연스러움)

### B4. 합의문에 "시험 기간"이라고 나옴 + "내일" 한 번짜리 문장이 1주 카드가 됨 [중간]
- 실제 문장: "내일 아침 8시에 휴게실에서 과외를 진행하며, 시험 기간은 1주일이고 10월 15일에 검토한다."
- "시험 기간"은 학생에겐 중간/기말로 읽힘. "체험 기간"이어야 함 (trial 직역으로 보임)
- "내일"로 박힌 카드라 모레부터는 뜻이 안 맞는데 7일 동안 바로 답 근거로 쓰임
- 이 문장 전체가 카드 격자 제목, S7 답 문장에 그대로 들어가서 길고 어색함

### B5. 알림만 가는 경우(S7)에도 B에게 "물어봐요"라고 감 [중간]
- 실제: "하늘이 알려왔어요. 답은 안 해도 돼요." 바로 아래 "하늘이 내일 아침 8시에 휴게실에서 과외를 해도 괜찮을지 물어봐요."
- 답 안 해도 된다면서 묻는 문장이라 앞뒤가 안 맞음. 말투 변환이 알림인지 질문인지 구분 안 하는 듯

### B6. 먼저 고른 사람은 합의 소식을 홈에서 못 받음 [중간]
- 재현: S6에서 A가 먼저 고르고 편지 화면에 있다가, B가 고른 뒤 홈으로 감
- 실제: B는 홈으로 자동 이동 + "둘 다 같은 안을 골랐어요. 카드로 만들었어요." A는 편지 화면에 띠 하나만 생기고 홈은 "무슨 일이에요?"
- 덧붙여 합의 뒤에도 편지 상태줄이 "각자 조건 듣는 중 · 하늘 답함 · 바다 답함"으로 남아 있음 (대안 단계, 합의 뒤 모두)

### B7. "직설적으로" 말투가 거의 반영 안 됨 [중간]
- A를 직설적으로 바꾼 뒤 받은 문장: "바다가 아침에 드라이기 소리 때문에 자꾸 깨서 아침 시간에 드라이기 사용을 조금만 줄여줄 수 있는지 물어봐요."
- 설정 예시("B 부탁: 평일 7:30 드라이기, 욕실에서 가능?")와 거리가 멂. 부드럽게 쪽은 "혹시 ... 될까요"로 티가 남

### B8. 위험 표현 응답이 17초 [낮음~중간]
- 다른 호출은 2~5초인데 S9만 17.0초. 그동안 "무슨 얘긴지 읽고 카드랑 맞춰보는 중이에요."만 보임. 1회만 재서 편차인지는 모름

### B9. 보낸 뒤 확인 문구가 상대 답을 가림 [낮음]
- "바다에게 물어볼게요. [알겠어]"를 안 누른 상태에서 답이 오면 편지 탭 숫자만 올라가고 홈은 그대로. 눌러야 답이 보임 (S5, S6에서 두 번)

### B10. 제안 카드 제목과 질문이 안 맞음 [낮음]
- 제안 카드 "아침 드라이기 사용 제한" 아래 "하늘이 이걸 하고 싶을 때 / 먼저 물어봐줘 / 그냥 해도 돼". "사용 제한을 하고 싶을 때"가 돼서 뭘 고르는지 헷갈림. 제목이 행동("아침에 방에서 드라이기 쓰기")이어야 질문과 맞음

## 4. 문구, UX 메모

- S4 보류 중 그림: 요정이 B 침대에서 자는 게 아니라 편지 든 채 러그에 서 있음. 코드상 의도(queued면 letter 자세)로 보이는데, "일어나면 전할게요"와는 B 침대 옆에서 기다리는 쪽이 더 맞아 보임
- 부탁(S5)을 보낼 때도 "하늘에게 물어볼게요."라고 나옴. 부탁이면 "전할게요"가 맞음
- 내 답이 내 편지 화면에 "조건이 있으면 괜찮대요.", "이번엔 어렵대요."로 나옴. 내가 한 말인데 전해 들은 말투
- 부드럽게 변환 문장 "하늘이 주말에 친구를 데려와도 괜찮을지 혹시 물어봐도 될까요, 바다?" - 물어봐도 되냐고 묻는 꼴이라 어색. 위에 "하늘이 물어봐요."가 이미 있어서 "하늘이"도 겹침
- 답 버튼 말투 섞임: "응, 괜찮아" / "조건 있으면 괜찮아"는 반말, "이번엔 어려워요"는 존댓말. 개인 질문(C2)은 반말("왜 꼭 ... 해야 해?")인데 보라는 다른 데서 존댓말
- 부탁에 대한 답 버튼이 허락용 그대로임. "드라이기 줄여줄래?"에 "조건 있으면 괜찮아"로 "8시 전에는 욕실에서 말릴게"를 보내는 게 어색
- "맞춰보기 전에 나한테만 몇 가지 물어볼게요." - 보라가 하는 말인데 "나"가 사용자를 가리켜서 헷갈림. B는 하늘이 맞춰보기를 골랐다는 설명 없이 이 문장부터 봄
- 편지 화면 "보라가 이렇게 읽었어요: 상대에게 확인 필요" - "상대" 대신 이름
- "지금 방 불 켜도 돼?"가 B가 깬 뒤에 "지금" 칩 그대로 전달됨. 한참 뒤일 수 있음
- "친구 데려와도 돼?"에 언제까지, 몇 명인지 되묻지 않고 바로 보냄 (가짜 AI QA에선 되물었음). 카드 설명이 "몇 시까지인지만 알면 대부분 괜찮다."인 것과 어긋남
- 대안 화면에 같은 제목이 설명 카드 3개 + 버튼 3개로 두 번 나옴. 화면 반이 중복
- 상대가 뭘 골랐는지("하늘 고름")가 내가 고르기 전에 보임. 의도면 괜찮은데 따라 고르게 될 수 있음
- "같은 버전의 같은 안을 둘 다 골라야 합의돼요." - "버전"은 사용자에게 뜻이 안 통함
- 합의 직후 카드 상세에 "잘 맞아, 1주 더 / 조금 바꾸고 싶어 / 그만할래"가 바로 있음. 만든 날 "1주 더"는 이름
- 바로 답 받은 것도 A 편지함에 "하늘 → 바다"로 뜸. 바다에겐 간 적 없음
- "바다가 카드를 고쳤어요."에 뭘 고쳤는지(15분 이내 추가)가 없음
- 안 정한 카드가 있으면 방 그림 요정 옆에 "!"만 뜸. 뭔지 알려면 눌러봐야 함
- 위험 표현 안내가 피해자용("괴롭힘을 느낀다면")인데 이 문장은 보낸 사람이 보는 화면
- 편지가 길면 방 그림이 위로 밀려 요정이 화면 맨 위에 걸림 (B 화면, 편지 + 칩 + 입력 + 버튼 3개일 때)
- 카드 설명글("늦은 밤의 통화는 속삭여도 크게 들린다." 등)과 보류 안내 글씨가 아주 작음
- 카드 탭 제목 "우리 방 카드"에 파란 포커스 테두리가 보일 때가 있음 (B 화면 스크린샷)
