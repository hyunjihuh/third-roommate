## 2. 남은 버그 (심각한 순)

### R1. 직설적으로 말투가 문장에 따라 거의 안 달라짐 [중간] (이전 B7)
- 재현: B 설정 → 직설적으로. A "너 침대에 잠깐 앉아도 돼?"
- 실제: "지금 네 침대에 잠깐 앉아도 괜찮아?". 부드럽게로 바꾸면 "혹시 지금 네 침대에 잠깐 앉아도 괜찮을까?". 6글자 차이
- 원문에 없던 "지금"이 양쪽 다 붙음 (칩에도 [지금]). 원문보다 길어짐
- 같은 편지를 다시 그리면 직설 문장이 "괜찮아?" → "돼?"로 바뀜. 말투를 바꿀 때마다 새로 변환하는 듯해서 같은 편지 문장이 볼 때마다 달라질 수 있음
- 원문이 이미 짧은 반말이면 직설 쪽은 원문 그대로 보여주는 게 나아 보임

### R2. 합의 뒤에도 편지 상태줄이 "각자 조건 듣는 중" [낮음~중간] (이전 B6 뒷부분)
- 재현: 5번을 끝낸 뒤 그 편지 열기 (카드 상세 → 어떻게 정했는지 보기)
- 실제: "각자 조건 듣는 중 · 하늘 답함 · 바다 답함" 바로 아래 "카드가 됐어요 / 보기 ▶". 대안 단계에서도 같은 문구
- 덧붙여 이 화면에는 골랐던 대안 3개와 누가 뭘 골랐는지가 사라져서, "어떻게 정했는지 보기"로 들어와도 정한 과정이 안 보임

### R3. 대안과 카드 상세에 한쪽 양보만 적힘 [낮음~중간]
- 대안 3개 모두 "하늘: 과외 시간을 1시간 늦춤" 식으로 하늘 쪽만 있고 바다 쪽 설명이 없음. 카드 상세도 "하늘 과외 시간을 1시간 늦춤" 한 줄뿐
- 이번 안은 실제로 하늘만 바꾼 게 맞긴 한데, 바다가 뭘 얻었는지/받아들였는지 한 줄이 없어서 "같이 만든" 느낌이 약함
- 대안 설명 줄에 "내일 아침 9시, 방"처럼 "내일"이 남아 있음 (합의 문장에선 빠짐)

### R4. 보낸 뒤 확인 문구가 상대 답을 가림 [낮음] (이전 B9, 그대로)
- "바다에게 물어볼게요. [알겠어]"를 안 누른 채 답이 오면 편지 탭 숫자만 1이 되고 홈 말풍선은 그대로. 눌러야 "바다의 답이에요."가 나옴 (이번에 3번 모두)

### R5. 합의 알림 버튼이 양쪽이 다름 [낮음]
- A(먼저 고름) 홈: [좋아] [카드 보기]. B(나중에 고름) 홈: [좋아]만

### R6. 방 나가기에 확인 단계 없음 [낮음]
- 설정 → 방 나가기를 누르면 바로 첫 화면. 같은 기기라 코드만 넣으면 같은 자리로 돌아오긴 하지만, 코드를 안 적어둔 사람은 못 돌아옴. 첫 화면에 방금 나온 방 코드도 안 남음

## 3. 문구 메모

- 합의 문장 "하늘은 앞으로 1주 동안 아침 9시에 방에서 과외를 해요." - 조건은 다 통과하지만 규칙보다는 일정 안내처럼 읽힘. "1주 동안"이 카드 아래 "1주 체험 중 · 7일"과 겹침. "아침 과외는 9시부터 방에서" 같은 꼴이면 카드 제목, 바로 답 인용에 더 잘 맞음
- 바로 답 "…과외를 해요." 카드에서 둘 다 괜찮다고 했어요." - 인용한 문장이 "~해요."로 끝나서 뒤 문장과 이어 읽기 어색
- B 개인 질문 1 "몇 시 이후면 괜찮을 것 같아?" - B가 방금 "9시 전엔 자고 있어"라고 적은 걸 다시 묻는 꼴
- 내가 한 답이 내 편지 화면에 "이번엔 어렵대요. 대신 같이 맞춰볼 수 있어요."로 나옴 (B 화면, 이전 메모 그대로). "대신 같이 맞춰볼 수 있어요"는 A에게만 뜻이 있는 말
- 부탁 문장(A가 받은 것) "혹시 아침에 드라이기 소리 때문에 자꾸 깨서, … 맞춰줄 수 있을까?" - "혹시"가 이유 앞에 붙어 어색하고 주어("내가")가 없어서 누가 깨는지 한 번 더 읽게 됨. "사용하는 시간을 조금만 맞춰줄"은 뭘 해달라는 건지 흐림 (초안 "조금 조절해 줄래?"도 같음)
- 칩 "상대 침대에 앉기" - "상대" 대신 받는 사람 기준 "내 침대" 또는 이름
- 편지 화면 "보라가 이렇게 읽었어요: 상대에게 확인 필요" - "상대" 그대로 (이전 메모)
- 부탁에도 답 버튼이 "응, 괜찮아 / 조건 있으면 괜찮아 / 이번엔 어려워요" 그대로, 반말과 존댓말 섞임 (이전 메모)
- "같은 버전의 같은 안을 둘 다 골라야 합의돼요." - "버전" 그대로 (이전 메모)
- 대안 화면에 같은 제목이 설명 3개 + 버튼 3개로 두 번 나옴 (이전 메모)
- 룸메 이름이 없을 때 A 정하기 화면은 여전히 "B가 이걸 하고 싶을 때" (B가 이름을 넣기 전). "룸메가"가 자연스러움
- 기숙사 규칙 안내 "기숙사 규칙에 걸려요: "외부인 방에서 자고 가기"" - 뜻은 통함. 누구에게 물어야 하는지(사감실 등) 한 줄 있으면 끝이 덜 막힘
- B 화면에서 "답을 전했어요" 토스트가 한참 뒤 덤프에도 남아 있었음. 탭이 뒤에 있어 타이머가 늦어진 것일 수 있어 버그로는 안 올림

## 4. 확인 못 한 것

- 직설 말투는 편지 3건으로만 봄. 부탁(7번)은 A 말투가 부드럽게인 상태로만 확인
- 7번 부탁 편지는 A가 답하지 않은 채로 남겨둠 (A 홈에 "바다가 부탁해요." 떠 있음)
- "다 어려워요", "그래도 바다에게 물어봐줘", 자는 중 보류, 위험 표현, 1주 만료 뒤 흐름은 이번 범위 밖이라 안 봄
- AI 응답 시간은 이번엔 안 잼 (뒤에 있는 탭에서 타이머가 늦어져 측정이 부정확)
